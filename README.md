This is an R Shiny app that helps compare the segmentation of two persons
It takes two data files that are created with the R Shiny app segmentation.
See https://github.com/EllenMKok/segmentation_comparison.git

The app can be run on https://01a11ac3-535f-2411-af83-242c3d91aa77.share.connect.posit.cloud/ or locally.

The segmentation comparison is based on Strijbos, J.-W., Martens, R. L., Prins, F. J., & Jochems, W. M. (2006). Content analysis: What are they talking about? Computers & Education, 46(1), 29–48. https://doi.org/10.1016/j.compedu/2005.04.002 .
